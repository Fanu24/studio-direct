# Bundled font sources

The existing Bricolage Grotesque, Figtree and JetBrains Mono families are bundled locally to avoid a build-time Google Fonts request. No font-family redesign is introduced. Original, unmodified variable TTF files and their SIL Open Font License notices are included. Pinned source URLs and SHA-256 checksums are recorded in `sources.json`.

The files are loaded through [Next.js local fonts](https://nextjs.org/docs/app/api-reference/components/font#local-fonts).
